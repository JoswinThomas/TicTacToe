# TicTacToe

A lightweight, interactive, object-oriented Tic-Tac-Toe game playable directly in your terminal, built using Python.

## 🚀 Features
* **Interactive Gameplay**: Play as either **X** or **O**.
* **Dynamic Turn Ordering**: 
  * Choosing **X** lets you go first.
  * Choosing **O** lets the computer go first.
* **Robust Input Validation**: The game catches invalid letters, numbers out of bounds, and occupied squares, requesting a new input without crashing.
* **Automated Opponent**: Includes a computer player utilizing automated random choice selection.
